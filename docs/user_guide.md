# IT Interview Practice Simulator - User Guide

## Introduction
Welcome to the IT Interview Practice Simulator! This application is designed to help Help Desk professionals and Network Administrators prepare for technical interviews by walking through simulated, scenario-based tasks. 

## Features
1. **Interactive Scenarios**: Choose from multiple IT support scenarios, categorized by difficulty.
2. **Terminal Simulation**: Practice command-line diagnostics with simulated outputs for commands like `ping`, `ipconfig`, and `nslookup`.
3. **Instant Feedback**: After resolving a scenario, receive an evaluation and tips on how to talk about the scenario during a real interview.

## How to Use the Simulator
1. **Launch the App**: Open the dashboard to see all available scenarios.
2. **Select a Scenario**: Click on any scenario card (e.g., "DNS Resolution Failure") to begin.
3. **Read the Briefing**: Look at the "Initial State" and "Task" descriptions on the sidebar.
4. **Troubleshoot**: Use the terminal to run diagnostic commands. See how the mock system responds.
5. **Resolve & Evaluate**: Once you have identified the issue, click "Mark as Resolved" in the sidebar. Read the solution and interview tips to compare with your own approach.

## Best Practices for Interview Prep
- **Talk Out Loud**: As you type commands into the terminal, explain *why* you are doing it, just as you would to an interviewer.
- **Start Simple**: Always check physical connections (simulated here as basic connectivity like `ping 8.8.8.8`) before jumping into complex diagnostics.
- **Review Feedback**: The feedback section provides key phrases and concepts interviewers look for.
